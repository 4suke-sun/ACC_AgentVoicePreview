出典URL付きで報告してください。

## 主要な参照先

- Agentic voice: https://docs.aws.amazon.com/connect/latest/adminguide/agentic-voice.html
- Agentic voice設定ガイド: https://docs.aws.amazon.com/connect/latest/adminguide/agentic-voice-configuration-guide.html
- StartWebRTCContact API: https://docs.aws.amazon.com/connect/latest/APIReference/API_StartWebRTCContact.html
- StopContact API: https://docs.aws.amazon.com/connect/latest/APIReference/API_StopContact.html
- フロー言語(Flow language): https://docs.aws.amazon.com/connect/latest/APIReference/flow-language.html
- Play promptの動的テキスト: https://docs.aws.amazon.com/connect/latest/adminguide/create-dynamic-text-strings.html
- Amazon Chime SDK JS: https://aws.github.io/amazon-chime-sdk-js/

## 報告形式

1. 質問への直接の回答(確認できた事実のみ)
2. 出典URL(参照した節がわかるように)
3. ドキュメントに記載がなく確認できなかった点(あれば明示する。推測で埋めない)
4. このリポジトリの実装への影響(該当ファイルを挙げる)
